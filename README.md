# SolarCards

Home Assistant Lovelace-Karte für Solarerzeugung als Balkendiagramm mit Prognoselinie.

> Projekt im Aufbau – Installationsanleitung und Beispielkonfiguration folgen, sobald die Karte
> funktionsfähig ist (siehe Schritt "HACS/Release-Setup").

## Entwicklung

```bash
npm install
npm run start   # baut im Watch-Modus und startet einen lokalen Server für dist/
```

Die gebaute Datei liegt danach unter `dist/solar-cards.js` und ist per lokalem Server unter
`http://<dein-rechner>:5000/solar-cards.js` erreichbar.
